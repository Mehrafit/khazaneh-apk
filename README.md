## نسخهٔ ۳٫۳۷ — رفع کرش تب «برنامه‌ریزی» 🛠

- کرش کامل اپ («Application error») هنگام باز شدن تب برنامه‌ریزی برطرف شد
- ریشهٔ باگ: خطای کامپایلر (متغیر موقتِ بدون declare) — همهٔ نقاط مشابه هم امن شدند
- روی نسخهٔ ۳٫۳۶ مستقیم به‌صورت **آپدیت** نصب می‌شود — دیتای شما سر جایش می‌ماند ✅

## نسخهٔ ۳٫۳۶ — پل بومی اندروید

- ذخیرهٔ واقعی بکاپ (اکسل/PNG/JSON) در پوشهٔ Download گوشی
- چاپ / ذخیرهٔ PDF با فریم‌ورک چاپ اندروید
- یادآور روزانهٔ واقعی (AlarmManager — بعد از ری‌بوت هم کار می‌کند)
- دکمهٔ بازگشت گوشی داخل اپ کار می‌کند
- سقف رایگان خزانه‌یار: ۲۰ سوال در ماه (پلن‌های خرید: به‌زودی)

## امکانات

- دخل و خرج، اقساط و چک، طلب‌ها، بودجه و دسته‌ها
- برنامه‌ریزی: کارها، عادت‌ها با سکه، رویدادها و تولدها
- خزانه‌یار: دستیار هوشمند آفلاین با تحلیل واقعی دیتای شما
- تقویم شمسی (پشتیبانی کامل سال کبیسه مثل ۱۴۰۸)
- بکاپ: اکسل، PDF، اینفوگرافیک PNG، فایل JSON + بکاپ خودکار هفتگی
- ویجت صفحهٔ گوشی (موجودی + کارهای امروز)
- قفل حریم خصوصی با رمز (PBKDF2 — ۲۱۰ هزار دور)
- کاملاً آفلاین — بدون اینترنت، بدون سرور، دیتا فقط روی گوشی شما
